## 1. Реализованная архитектура

В качестве стека для Cloud Web-версии выбрана современная web-native архитектура:
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons.
- **Backend / Persistence / Auth:** Firebase Authentication (Google / Email) + Cloud Firestore (`workspaces/{workspaceId}/...` с изоляцией тенантов и проверкой всех полей в `firestore.rules` и `firebase-blueprint.json`).
- **Доменное ядро (`src/core/`):**
  - `calculatorCore.ts` — единое расчётное ядро (потери брутто/нетто, масштабирование веса и диаметра форм, труд, упаковка, доставка, коммунальные ресурсы/оборудование/аренда, комиссия/эквайринг, целевая маржа/наценка, точка безубыточности, ROI, чистый денежный поток с учётом сторно).
  - `units.ts` — совместимые размерности единиц (г/кг, мл/л, шт) и плотность-зависимые конверсии `convertQtyWithDensity` (`мл ↔ г`).
  - `payrollEngine.ts` — расчёт зарплаты (почасовая, сдельная, процент, смешанная), совпадающий в предрасчёте и закрытии периода.
  - `moneyFormat.ts`, `pluralRu.ts` — форматирование копеек, скрытие сумм и русские числительные.
- **Дизайн-система Soft Atelier (`src/index.css`, `src/components/AppShell.tsx`, `src/components/UiPrimitives.tsx`):**
  - 4 темы: **Berry Cream**, **Vanilla Pistachio**, **Porcelain**, **Dark Chocolate**.
  - 3 режима плотности интерфейса (`standard`, `compact`, `spacious`).
  - Адаптивная оболочка: desktop sidebar, мобильная панель с настраиваемыми закреплёнными вкладками (до 3), глобальный поиск (`Ctrl+K`), меню быстрого создания (`+`) с выбором существующих позиций склада, центр уведомлений (просрочки, низкие остатки, истекающие партии), скрытие денежных сумм.

## 3. Что ещё предстоит для полного выхода за рамки Web-пилота (Этапы 12–16 и Addendum)

Если развивать продукт дальше от текущего готового веб-пространства к полной сетевой/мультиплатформенной платформе:
1. **Торговые точки и POS (Этап 13):** отдельный раздел витрин, перемещения продукции между кухней и точками, интерфейс кассира и кассовые смены.
2. **Многопользовательские аккаунты и RBAC (Этап 12):** поток приглашений сотрудников по email/ссылке, принятие приглашения и скрытие себестоимости/финансов на уровне UI в зависимости от роли.
3. **Печатные документы заказов:** генерация сметы, счёта и акта по заказу (в дополнение к уже работающей печати техкарты рецепта).
4. **SaaS-монетизация (Этап 15):** биллинг подписки 499 ₽/мес, лимиты и льготный период чтения/экспорта.
5. **Автономная редакция Personal (`Sweet_Studio_Personal_Addendum.md`):** локальный SQLite-адаптер, десктоп/мобильные установщики (Windows EXE/MSIX, Android APK), офлайн-лицензирование и мастер миграции `Personal → Cloud`.
6. **Автоматизированные приёмочные тесты (T01–T20):** покрытие unit/integration/E2E-тестами доменного ядра и изоляции тенантов.
