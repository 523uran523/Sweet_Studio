# SweetStudio — Актуальный статус разработки (PROGRESS)

**Дата обновления:** 2026-11-27  
**Статус:** Основное ядро, этапы A–E и шаги **F1–F6** (вход Email/пароль + Google SSO, автосохранение черновиков и PWA, сканер QR и штрихкодов на POS, межточечные перемещения `StockTransfer`, многопозиционные заказы, PDF-расчётный листок, повторяющиеся задачи и уведомления с Telegram-сводкой) реализованы и подключены.

## 1. Реализованная архитектура

В качестве стека для Cloud Web-версии выбрана современная web-native архитектура:
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons, jsPDF (со встроенным кириллическим шрифтом Liberation Sans).
- **Backend / Persistence / Auth:** Firebase Authentication (Google / Email) + Cloud Firestore (`workspaces/{workspaceId}/...` с изоляцией тенантов, `memberUids`, `/invitations` и проверкой всех полей в `firestore.rules` и `firebase-blueprint.json`).
- **Доменное ядро (`src/core/`):**
  - `calculatorCore.ts` — единое расчётное ядро (потери брутто/нетто, масштабирование веса и диаметра форм, труд, упаковка, доставка, коммунальные ресурсы/оборудование/аренда, комиссия/эквайринг, целевая маржа/наценка, точка безубыточности, ROI, чистый денежный поток с учётом сторно).
  - `units.ts` — совместимые размерности единиц (г/кг, мл/л, шт) и плотность-зависимые конверсии `convertQtyWithDensity` (`мл ↔ г`).
  - `payrollEngine.ts` — расчёт зарплаты (почасовая, сдельная, процент, смешанная), совпадающий в предрасчёте и закрытии периода.
  - `posCore.ts` — расчёт кассовых смен, ожидаемой наличности, расхождения Z-отчёта, корзины POS, валидации купонов и распознавания сканируемых кодов (`resolvePosScannedCode`).
  - `ordersCore.ts` — нормализация и расчёт итогов многопозиционного заказа (`OrderItem[]`), сводки и пропорциональная атрибуция выручки/труда по рецептам.
  - `workRecurrence.ts`, `notifications.ts` — планирование повторов задач (`seriesId`/`occurrenceIndex`) и приоритизация уведомлений/Telegram-сводки.
  - `locations.ts` — разрешение точки по умолчанию, фильтрация сущностей по `activeLocationId` (`matchesLocationFilter`) и расчёт разбивки выручки/склада по точкам (`computeLocationBreakdown`).
  - `rbac.ts` — матрица ролей (`owner`, `admin`, `confectioner`, `seller`, `marketer`, `storekeeper`, `accountant`), фильтрация навигации, рецептов и финансовых сумм.
  - `subscription.ts` — жизненный цикл подписки (14 дней триал, 7 дней льготный период, `canWrite`/`canExport`, `499 ₽/мес`).
  - `moneyFormat.ts`, `pluralRu.ts` — форматирование копеек, скрытие сумм и русские числительные.
- **Дизайн-система Soft Atelier (`src/index.css`, `src/components/AppShell.tsx`, `src/components/UiPrimitives.tsx`):**
  - 4 темы: **Berry Cream**, **Vanilla Pistachio**, **Porcelain**, **Dark Chocolate**.
  - 3 режима плотности интерфейса (`standard`, `compact`, `spacious`).
  - Адаптивная оболочка: desktop sidebar, мобильная панель с настраиваемыми закреплёнными вкладками (до 3, с автозаполнением по ролям), **глобальный переключатель активной точки (`locationId`)**, глобальный поиск (`Ctrl+K`), меню быстрого создания (`+`, фильтруемое по RBAC и подписке), центр уведомлений (просрочки, низкие остатки, истекающие партии), скрытие денежных сумм и баннеры статуса подписки/RBAC-роли.

## 3. Дальнейшее развитие (Future Roadmap)

1. **Внешнее хранилище фотографий (`F7`):** перенос фотографий рецептов, портфолио и жалоб качества из Base64 в Firebase Storage / S3.
2. **Продакшен-биллинг и фискализация (`F8`):** интеграция вебхуков платёжных шлюзов (ЮKassa / CloudPayments) и фискальных регистраторов ККТ (54-ФЗ).
3. **Автономная редакция Personal (`Sweet_Studio_Personal_Addendum.md`):** локальный SQLite-адаптер, десктоп/мобильные установщики (Windows EXE/MSIX, Android APK), офлайн-лицензирование и мастер миграции `Personal → Cloud`.
