## Очередь доработок (от простого к сложному)

1. **F1 (Простой) — Логин/пароль (Email/Password), стандартный SaaS-экран входа и привязка к почте** — ✅ *Выполнено*
   - Минималистичный экран входа по стандарту SaaS: кнопка «Продолжить с Google» сверху, единая форма `Email + Пароль` со встроенной ссылкой «Забыли пароль?» и нижним переключателем «Вход / Регистрация».
   - Подтверждение почты (`sendEmailVerification`) с экраном ожидания перед входом в Firestore-пространство (`isVerified()` в `firestore.rules`).
   - Автоматический fallback на `signInWithRedirect` + `getRedirectResult` при блокировке popup в мобильных браузерах/WebView.
   - Раздел «Аккаунт, пароль и привязка к почте» в Настройках: привязка пароля к Google-аккаунту, привязка/смена email (`verifyBeforeUpdateEmail`), привязка Google к Email-аккаунту.

2. **F2 (Простой–средний) — Автосохранение черновиков форм и PWA-кэш** — ✅ *Выполнено*
   - Автосохранение недописанных форм заказа и рецепта в `localStorage` (`draftStorage.ts`) с восстановлением после перезагрузки и кнопкой очистки.
   - Полноценная поддержка PWA (`vite-plugin-pwa`, Web App Manifest, иконки `192x192` / `512x512` / `maskable` / `apple-touch-icon`, Workbox-кэш ассетов, кнопка установки приложения для ПК/Android/iOS и индикатор оффлайна).

3. **F3 (Средний) — Камера и сканер QR/штрихкодов на кассе POS** — ✅ *Выполнено*
   - Камера (`PosScannerModal` на базе `html5-qrcode`) на `PosPage`: сканирование QR-кодов и штрихкодов (`EAN-13`, `Code-128`, `QR` и др.) с выбором камеры, загрузкой с фото и ручным fallback.
   - Поиск по коду с аппаратного USB/Bluetooth-сканера по `Enter` в строке поиска кассы и сканирование купона прямо из блока чека (с автоподстановкой владельца для персональных купонов).
   - Печатные карточки купонов в `LoyaltyPage` теперь генерируют настоящий ISO-совместимый QR-код (`QrCodeSvg` на базе `qrcode`).

4. **F4 (Средний) — Перемещения между точками (`StockTransfer`) и глобальный фильтр по точке** — ✅ *Выполнено*
   - Глобальный переключатель активной точки (`activeLocationId`, с сохранением в `localStorage`) в шапке `AppShell` и мобильной панели, а также фильтрация в «Кладовой», «Производстве», «Кассе (POS)» и «Аналитике».
   - Вкладка «Перемещения» в «Кладовой»: отправка позиций и партий FEFO между кухней, складом и витриной (`createStockTransfer`), приёмка на целевую точку с автоматическим пополнением остатков/партий (`receiveStockTransfer`) и отмена с возвратом (`cancelStockTransfer`).
   - Сводная таблица «Разбивка по точкам» в «Аналитике» (заказы, чеки POS, признанная выручка и стоимость склада по каждой точке).

5. **F5 (Средний) — Многопозиционный заказ** — ✅ *Выполнено*
   - Состав заказа из нескольких позиций (`OrderItem[]` в `ordersCore.ts` + таблица позиций в форме создания/редактирования и карточке заказа): рецепты и произвольные позиции, общий вес, цена, себестоимость, объединённые аллергены, списание сырья по FEFO для всех позиций, многопозиционный PDF Счёт-смета/Акт (`pdfExporter.ts`) и пропорциональная атрибуция в Аналитике.

6. **F6 (Средний+) — Модульные доработки по ТЗ** — ✅ *Выполнено*

7. **F7 (Сложный) — Вынос фотографий в Firebase Storage / S3** — ⏳ *В планах*

8. **F8 (Сложный) — Боевой биллинг, фискализация ККТ и редакция `Personal`** — ⏳ *В планах*

   - Отдельная автономная редакция `Personal` (локальный SQLite без интернета, установщики Windows/Android, мастер миграции `Personal → Cloud`).

## Настройка окружения для запуска (Firebase Console)

1. **Включить Email/Password (обязательно при ошибке `auth/operation-not-allowed`):**
   - Откройте *Firebase Console → ваш проект (`utopian-karst-3drm3`) → Build → Authentication → Sign-in method*.
   - Нажмите **Add new provider** (или выберите **Email/Password**), включите переключатель **Enable** и нажмите **Save**.
   - Проверьте, что провайдер **Google** также включён в этом списке.
2. **Добавить разрешённые домены (`auth/unauthorized-domain`):**
   - Откройте *Authentication → Settings → Authorized domains* и добавьте домен предпросмотра и свой домен сервера.
   - Для мобильных WebView при `signInWithRedirect` используйте рекомендации из [Firebase Redirect Best Practices](https://firebase.google.com/docs/auth/web/redirect-best-practices) (`/__/auth/handler`).
3. **Развернуть правила безопасности Firestore:**
   - `firebase deploy --only firestore:rules`.
