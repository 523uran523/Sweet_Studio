# Навигация по документации SweetStudio (`docs/`)

Эта папка содержит проектную документацию, спецификации, ассеты и планы развития **SweetStudio**. Актуальная сводка проекта и инструкции по запуску находятся в корневом [`README.md`](../README.md).

## Актуальные документы рабочего пилота (Web Cloud)

- **[`PROGRESS.md`](./PROGRESS.md)** — подробная таблица готовности всех модулей (Главная, Работа, Заказы/Заявки, POS-касса, Рецепты и Калькулятор, Кладовая/Производство, CRM/Лояльность, Качество/Продвижение, Финансы, Аналитика, Команда/RBAC, Настройки/Подписка, Академия).
- **[`Remaining_Tasks.md`](./Remaining_Tasks.md)** — упорядоченный от простого к сложному план продакшен-доработок **Этап F (`F1 → F8`)** и чеклист настройки Firebase Authentication (`Email/Password`, `Google`, `Authorized domains`).
- **[`ОБЩИЙ_ПЛАН_ДОРАБОТОК.md`](./ОБЩИЙ_ПЛАН_ДОРАБОТОК.md)** — результаты аудита финансовой и складской логики, сверка расчётного ядра с таблицей «Цена торта» (`Tsena_torta_rubli.xlsx`), этапы **A–E** и детализация **Этапа F (`F1 → F8`)**.

## Исходные спецификации и визуальные материалы

- **[`Sweet_Studio_TZ.md`](./Sweet_Studio_TZ.md)** — полное техническое задание (карта переноса из Masters, ролевая модель, дизайн-система Soft Atelier, функциональные требования и сценарии приёмки `T01–T20`).
- **[`Sweet_Studio_Personal_Addendum.md`](./Sweet_Studio_Personal_Addendum.md)** — спецификация будущей автономной редакции **Personal** (локальный SQLite без сети, десктоп/мобильные пакеты, оффлайн-лицензия, мастер миграции `Personal → Cloud`).
- **[`Sweet_Studio_Наброски.md`](./Sweet_Studio_Наброски.md)** — ранние заметки и черновые идеи к проектированию.
- **[`Sweet_Studio_reference.html`](./Sweet_Studio_reference.html)** — визуальный HTML-референс палитр и компоновки **Soft Atelier**.
- **`Sweet_Studio.ico` / `Sweet_Studio_icon.png`** — исходники иконки приложения (ягодный фон `#A45C7A`, кремовый десерт `#FFF6ED`).
